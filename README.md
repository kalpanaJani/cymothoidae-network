# Global Host-Parasite Interaction Network of Marine Isopods (Cymothoidae)

## Project Overview
This independent research project constructs and analyzes a global ecological network mapping the interactions between parasitic tongue-eating marine isopods (**Family Cymothoidae**) and their teleost fish hosts. 

## Core Objectives
* Isolate and clean global species interaction records from open-access repositories.
* Construct an ecological network model using network topology metrics.
* Deploy an open-source, interactive network visualization for reproducible research workflows.

## Data Source
The primary interaction dataset consists of 491 unique species interactions across 38 parasite species and 311 host species, sourced from the **Global Biotic Interactions (GloBI)** database.
